# Changelog of tesserae-shell-config

Releases are GitHub Releases only (tag `config-vX.Y.Z`), never PyPI. The notes of a release are its `## X.Y.Z` section here.

## 0.1.0

The first release of the Tesserae Shell configuration application: a graphical editor for the shell's `.tdl` files (Files, Structure, Form, Text and Problems areas), built on Tesserae UI. See the README for what it does and the keyboard map. Needs Python 3.14 and the `tesserae-shell` command.
